# システムアップデート

plumOSは署名付きアップデートアーカイブを使用します。通常のアップデートでは、
StockOS由来の固定カーネルとブートローダーを置き換えません。

## アップデートの種類

- **Runtime Update** は、ext4システム領域にあるフロントエンド、アプリ、
  エミュレータ、ライブラリ、ファクトリー設定などのplumOS管理ファイルを更新します。
- **System Update** は、使用していないA/Bスロットへ読み取り専用Linux SquashFSを
  書き込みます。

## アップデート手順

1. POWKIDDY V90S用のアップデートアーカイブを取得します。展開しないでください。
2. `.tar.gz`ファイルをSD1の`PLUMOS/updates/`へコピーします。カードリーダー、
   USB Disk Mode、または絶対パス`/mnt/plumos-user/updates/`へのSFTP・SSHを使用します。
3. 安全に取り外すか切断します。
4. `START -> システム設定 -> システムアップデート`を開きます。
5. Aボタンで最新の互換性がある署名済みパッケージを選びます。
6. 検査、インストール、再起動が終わるまで安定した電源へ接続します。

アップデート中はフロントエンドの操作がロックされます。Reset、電源断、SDカードの
取り外しを行わないでください。

## 復旧とログ

Runtime Updateは、ロールバック用に直前の1トランザクションだけを保持します。
System Updateは未使用のシステムスロットへ書き込み、新しいスロットがフロントエンド
まで到達しない場合は以前のスロットへ戻ります。

PCから読める最新の失敗概要は次へコピーされます。

```text
PLUMOS/plumos-logs/update/
```

`PLUMOS/updates/`内のアーカイブはユーザー管理です。更新後の正常起動を確認してから、
不要になった古いアーカイブを削除してください。
