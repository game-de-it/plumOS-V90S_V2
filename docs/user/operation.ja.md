# 基本操作

## ゲーム一覧画面の操作

| 操作 | 動作 |
| --- | --- |
| 十字キー | カーソル移動・値の変更 |
| A | 開く・決定・起動 |
| B | 戻る |
| Y | 対応画面でお気に入り登録・解除 |
| START | STARTメニューを開く |
| SELECT | ゲームの起動方法を選ぶ |
| 電源ボタン | 電源メニューを開く |
| 音量 - / + | 12段階でシステム音量を変更 |
| SELECT + 音量 - / + | 対応している場合に画面の明るさを変更 |

ゲーム中に使えるボタン操作は、エミュレータによって異なります。
詳しくは各エミュレータのメニューで確認してください。

## 主な画面

- **TOP**: ROMが存在する機種を表示します。UI設定から空の機種、お気に入り、
  最近使った項目も表示できます。
- **ROMリスト**: 選択した機種のゲームを表示します。
- **ギャラリー**: サムネイルを表示し、長いタイトルはスクロールします。
- **START**: UI、システム、ネットワーク、Apps、ヘルプ、再起動、
  シャットダウンを開きます。
- **SELECT**: RetroArch、PicoArch、スタンドアロンから、ゲームの起動方法を
  選びます。表示される選択肢は機種によって異なります。

ROMを追加・削除した後は`START -> UI設定 -> TOP画面を更新`を実行します。

## 電源操作

STARTメニューまたは電源ボタンメニューから再起動・シャットダウンを実行します。
保存処理中はボタンを操作できません。画面が消えるまで待ってください。
スリープから戻るときは電源ボタンを押します。

## 音声

内蔵スピーカーでは、左右両方の音を1つのスピーカーから再生します。
対応USB DACでは左右別々のステレオ音声を再生します。ゲーム中にUSB DACを
抜き差しできますが、音が切り替わるまで少し待ってください。
