# 基本操作

## フロントエンド操作

| 操作 | 動作 |
| --- | --- |
| 十字キー | カーソル移動・値の変更 |
| A | 開く・決定・起動 |
| B | 戻る |
| Y | 対応画面でお気に入り登録・解除 |
| START | STARTメニューを開く |
| SELECT | エミュレータ・プロファイル選択を開く |
| 電源ボタン | 電源メニューを開く |
| 音量 - / + | 12段階でシステム音量を変更 |
| SELECT + 音量 - / + | 対応している場合に画面の明るさを変更 |

ゲーム内ショートカットはエミュレータごとに異なる場合があります。
各エミュレータのメニューで確認・変更してください。

## 主な画面

- **TOP**: ROMが存在する機種を表示します。UI設定から空の機種、お気に入り、
  最近使った項目も表示できます。
- **ROMリスト**: 選択した機種のゲームを表示します。
- **ギャラリー**: サムネイルを表示し、長いタイトルはスクロールします。
- **START**: UI、システム、ネットワーク、Apps、ヘルプ、再起動、
  シャットダウンを開きます。
- **SELECT**: 対象機種で利用できるRetroArch、PicoArch、スタンドアロンの
  プロファイルを選択します。

ROMを追加・削除した後は`START -> UI設定 -> TOP画面を更新`を実行します。

## 電源操作

フロントエンドまたは電源ボタンメニューから再起動・シャットダウンを実行します。
データ同期中は操作が無効になるため、完了まで待ってください。スリープは
サスペンドRAMを使用し、電源ボタンで復帰します。

## 音声

内蔵スピーカーでは左右チャンネルをモノラルミックスします。対応USB DACでは
ステレオ出力します。ゲーム中にUSB DACを抜き差しできますが、切り替わるまで
少し待ってください。
