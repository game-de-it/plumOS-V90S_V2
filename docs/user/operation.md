# Basic Operation

## Frontend Controls

| Control | Action |
| --- | --- |
| D-pad | Move the cursor or change a value |
| A | Open, confirm, or launch |
| B | Go back |
| Y | Add or remove a favorite where available |
| START | Open the START menu |
| SELECT | Choose how to launch the game |
| Power button | Open the power menu |
| Volume - / + | Change system volume through 12 steps |
| SELECT + Volume - / + | Change display brightness when supported |

Button shortcuts can differ between emulators. Check the emulator's menu for
details.

## Main Screens

- **TOP** lists systems that contain ROMs. UI Settings can also show empty
  systems, Favorites, and Recent.
- **ROM list** shows games for the selected system.
- **Gallery** shows available thumbnails and scrolls long titles.
- **START** opens UI, System, Network, Apps, Help, Restart, and Shutdown.
- **SELECT** chooses whether to use RetroArch, PicoArch, or a standalone
  emulator. The available choices depend on the system.

After adding or removing ROMs, run `START -> UI Settings -> Refresh TOP`.

## Power Actions

Use Restart or Shutdown from the START menu or the power-button menu. Buttons are
disabled while data is being saved, so wait until the screen turns off. Press
the power button to wake the V90S from sleep.

## Audio

The built-in speaker combines the left and right audio channels so both can be
heard. A supported USB DAC plays normal stereo sound. You can connect or remove
a USB DAC while a game is running; wait a moment for the sound to switch.
