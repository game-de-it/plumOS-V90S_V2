# セーブデータとスクリーンショット

plumOSは、使用中のセーブデータをLinuxのext4システム領域へ保存します。これにより、
FAT32ユーザー領域への書き込みを減らします。SDカードをWindowsやmacOSへ直接挿しても、
これらのフォルダは表示されません。

## RetroArchとPicoArch

セーブRAMとステートセーブはシステムごとに整理されます。

```text
/mnt/plumos/Saves/<system>/
/mnt/plumos/States/<system>/
```

通常、セーブファイル名はROMファイル名に対応します。他機種から移す場合は、
ベース名を同じにしてください。

```text
ROM:  Super Metroid.sfc
Save: Super Metroid.srm
```

## スタンドアローンエミュレータ

スタンドアローンエミュレータの書き込みデータは、次の場所に保存されます。

```text
/mnt/plumos/state/standalone/
```

内部構成は各エミュレータが管理します。コピーにはAppsのファイルマネージャー、
SFTP、またはSSHを使います。セーブデータを置き換える前にエミュレータを終了してください。

## スクリーンショット

RetroArchのスクリーンショットは、設定された次の画像ディレクトリを使います。

```text
/mnt/plumos/Images/
```

ほかのアプリは、それぞれの状態ディレクトリへ保存する場合があります。PCから直接
読みたい場合は、ファイルマネージャーやネットワークサービスでFAT32の`PLUMOS`
領域へコピーしてください。

## バックアップ

1. 実行中のゲームまたはアプリを終了します。
2. 対象のセーブディレクトリを別の機器へコピーします。
3. システム名、ROMのベース名、拡張子を維持します。
4. コピー完了後、安全に取り外すか切断します。

ゲーム実行中に使用中のセーブデータを上書きしないでください。
