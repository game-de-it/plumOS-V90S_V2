# セーブデータとスクリーンショット

RetroArchのセーブデータは、ROMと同じSDカードの`roms/`内へ保存されます。
SD2を使っている場合はSD2、SD2を使っていない場合はSD1の`PLUMOS`に入ります。
PicoArchやスタンドアローンエミュレータは保存場所が異なります。

## RetroArch

plumOSの初期設定では、通常セーブとステートセーブをROM側へ保存し、さらに
「ROMフォルダ名」と「使用したコア名」で分類します。

```text
roms/<ROMフォルダ>/<ROMフォルダ>/<コア名>/
```

### GBの例

`Aretha (Japan).gb`をGambatteコアで起動すると、実際には次のようになります。

```text
roms/GB/
  Aretha (Japan).gb
  GB/
    Gambatte/
      Aretha (Japan).srm
      Aretha (Japan).state.auto
      Aretha (Japan).state.auto.png
```

最初の`GB`はROMを入れたフォルダです。2つ目の`GB`はRetroArchの
「コンテンツのフォルダごとに分類する」設定、`Gambatte`は
「コアごとに分類する」設定によって作られます。

| ファイル | 内容 |
| --- | --- |
| `<ROM名>.srm` | ゲーム内の通常セーブ |
| `<ROM名>.state` | スロット0の手動ステートセーブ |
| `<ROM名>.state1`など | 番号付きステートセーブ |
| `<ROM名>.state.auto` | ゲーム終了時に作られる自動ステートセーブ |
| `<ステート名>.png` | ステートセーブのサムネイル |

通常セーブはゲーム中に約10秒間隔で書き出されます。終了時の自動ステートは
作成されますが、次回起動時には自動で読み込まれません。手動ステートは
自動インデックスが有効で、最大20世代を保持する設定です。

他機種からセーブを移す場合は、`.srm`より前の名前をROM名と同じにして、
使用するコアのフォルダへ入れてください。別のコアではセーブ形式が異なる場合があります。

## PicoArch

PicoArchのセーブはSD1のLinux用領域にある次の場所を使います。

```text
/mnt/plumos/Saves/<system>/
```

PCへ直接SDカードを挿しても、このフォルダは通常表示されません。Appsの
ファイルマネージャー、SFTP、またはSSHを使ってコピーしてください。

## スタンドアローンエミュレータ

専用エミュレータのセーブや設定は、次の場所に保存されます。

```text
/mnt/plumos/state/standalone/
```

中のフォルダ構成はエミュレータごとに異なります。セーブデータをコピーまたは
置き換える前に、ゲームを終了してください。

## スクリーンショット

RetroArchのスクリーンショットは、次の場所へ保存されます。

```text
/mnt/plumos/Images/
```

ほかのアプリは、別の場所へ画像を保存することがあります。PCへ持ち出す場合は、
ファイルマネージャーやネットワークサービスで`PLUMOS`へコピーしてください。

## バックアップ

1. 実行中のゲームまたはアプリを終了します。
2. 対象のセーブフォルダをPCや別のSDカードへコピーします。
3. ROMフォルダ名、コア名、ROMと同じファイル名、拡張子を変えないでください。
4. コピー完了後、安全に取り外すか切断します。

ゲーム実行中に使用中のセーブデータを上書きしないでください。
