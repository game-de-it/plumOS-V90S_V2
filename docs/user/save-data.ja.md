# セーブデータとスクリーンショット

セーブデータは、SD1内のPCから見えない場所へ保存されます。SDカードをWindowsや
macOSへ直接挿しても、セーブ用フォルダは表示されません。コピーする場合は、
Appsのファイルマネージャー、SFTP、またはSSHを使います。

## RetroArchとPicoArch

通常のセーブとステートセーブは、ゲーム機ごとに次の場所へ保存されます。

```text
/mnt/plumos/Saves/<system>/
/mnt/plumos/States/<system>/
```

通常、セーブファイル名はROMファイル名と同じ名前になります。他機種から移す場合は、
拡張子より前の名前を同じにしてください。

```text
ROM:  Super Metroid.sfc
Save: Super Metroid.srm
```

## スタンドアローンエミュレータ

専用エミュレータのセーブや設定は、次の場所に保存されます。

```text
/mnt/plumos/state/standalone/
```

中のフォルダ構成はエミュレータごとに異なります。セーブデータをコピーまたは
置き換える前に、ゲームを終了してください。

## スクリーンショット

RetroArchのスクリーンショットは、次の場所へ保存されます。

```text
/mnt/plumos/Images/
```

ほかのアプリは、別の場所へ画像を保存することがあります。PCへ持ち出す場合は、
ファイルマネージャーやネットワークサービスで`PLUMOS`へコピーしてください。

## バックアップ

1. 実行中のゲームまたはアプリを終了します。
2. 対象のセーブフォルダをPCや別のSDカードへコピーします。
3. ゲーム機名、ROMと同じファイル名、拡張子を変えないでください。
4. コピー完了後、安全に取り外すか切断します。

ゲーム実行中に使用中のセーブデータを上書きしないでください。
