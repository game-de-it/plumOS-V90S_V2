# plumOSのインストール

## 必要なもの

- POWKIDDY V90S
- SD1用の信頼できるmicroSDカード
- SDカードリーダーを備えたWindows、macOS、Linux PC
- リリース版plumOS V90S SDカードイメージ
- Raspberry Pi Imager、balenaEtcherなどのイメージ書き込みソフト

ROM・BIOS用として、FAT32のmicroSDカードをSD2へ追加できます。

## イメージを書き込む

1. 対象カード内の必要なファイルをバックアップします。書き込み時に全消去されます。
2. イメージ書き込みソフトでplumOS V90Sイメージを選択します。
3. SD1用カードを間違えないように選び、書き込みます。
4. 安全に取り出し、V90SのSD1スロットへ挿入します。
5. SD2は初回起動時には空にするか、[SDカードとフォルダ](storage.ja.md)の
   形式で準備したカードを使用します。

## 初回起動

V90Sを安定した電源へ接続して起動します。初回起動ではシステム領域の拡張、
FAT32ユーザーボリュームの作成、初期フォルダ配置を行うため、通常より時間がかかります。
plumOSフロントエンドが表示されるまで電源を維持してください。

初回起動中にResetを押したり、SDカードを抜いたりしないでください。
エラー画面が表示された場合は内容を控え、
[トラブルシューティング](troubleshooting.ja.md)を参照します。

## インストール後

SDカードを抜く前に`START -> シャットダウン`を実行してください。
PCへ接続して[SDカードとフォルダ](storage.ja.md)に従ってデータを置くか、
ネットワークサービスまたはUSB Disk Modeで転送します。
