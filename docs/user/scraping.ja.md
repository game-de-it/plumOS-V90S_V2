# サムネイルのスクレイピング

V90Sをネットワークへ接続すると、フロントエンドからROM用画像を取得できます。

## 画像の取得

1. 対応するUSB Wi-Fiアダプターを接続します。
2. `START -> ネットワーク設定`からWi-Fiへ接続します。
3. AppsまたはROMリストの該当操作からスクレイパーを開きます。
4. システムを選び、スクレイピングを開始します。
5. 画像がすぐに表示されない場合はTOPへ戻り、「TOPを更新」を実行します。

ダウンロード中は電源とネットワーク接続を維持してください。

## 画像の保存場所

画像はシステム別に次の場所へ保存されます。

```text
/mnt/plumos/Images/<system>/
```

例えばNES画像は`/mnt/plumos/Images/nes/`へ保存されます。画像のベース名はROMの
ベース名と一致させます。他のplumOS対応機種も同じ`Images/<system>`構成を使うため、
画像を機種間でコピーできます。

## 手動で画像を追加する

Appsのファイルマネージャー、SFTP、SSHを使って、対応画像を同じディレクトリへ
コピーできます。大量に置き換える場合はフロントエンドを終了し、完了後に再起動するか
「TOPを更新」を実行してください。
