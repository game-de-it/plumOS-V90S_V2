# サムネイル画像の取得

V90SをWi-Fiへ接続すると、ゲーム一覧に表示する画像をダウンロードできます。
この機能を「スクレイピング」と呼びます。

## 画像の取得

1. 対応するUSB Wi-Fiアダプターを接続します。
2. `START -> ネットワーク設定`からWi-Fiへ接続します。
3. AppsまたはROMリストから「スクレイピング」を開きます。
4. ゲーム機を選び、画像の取得を開始します。
5. 画像がすぐに表示されない場合はTOPへ戻り、「TOPを更新」を実行します。

ダウンロード中は電源とネットワーク接続を維持してください。

## 画像の保存場所

画像はゲーム機ごとに次の場所へ保存されます。

```text
/mnt/plumos/Images/<system>/
```

例えばNES画像は`/mnt/plumos/Images/nes/`へ保存されます。画像とROMは、拡張子より
前の名前を同じにしてください。他のplumOS対応機種も同じフォルダ構成を使うため、
画像を機種間でコピーできます。

## 手動で画像を追加する

Appsのファイルマネージャー、SFTP、SSHを使って、画像を同じフォルダへコピーできます。
大量に置き換える場合はゲーム一覧画面を終了してください。コピー後に起動し直すか、
「TOPを更新」を実行します。
