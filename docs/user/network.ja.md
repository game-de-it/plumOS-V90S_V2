# ネットワークとUSB接続

V90SにはWi-Fiが内蔵されていません。Wi-Fiを使うには、対応するUSB Wi-Fi
アダプターをOTGポートへ接続します。USB HUBを使う場合は、V90Sと相性の良い
電源付き製品を使ってください。

## Wi-Fi

1. USB Wi-Fiアダプターを接続します。
2. `START -> ネットワーク設定`を開きます。
3. Wi-FiをONにします。
4. 「Wi-Fiへ接続」を開いてスキャンし、SSIDを選びます。
5. 画面キーボードでパスワードを入力して確定します。

接続に成功すると設定が保存されます。時刻設定で自動時刻をONにすると、
Wi-Fi接続後に時計も合います。アダプターを抜いた後に再接続できない場合は、
アダプターを差し直してWi-FiをOFF、ONしてください。

### 対応Wi-Fiドライバー

現在のリリースには、次のRealtek USB Wi-Fiドライバーが入っています。

- `8192eu`
- `8723bu`
- `8812au`
- `8821cu`
- `88x2bu`
- `rtl8192cu`
- `rtl8xxxu`

実機で確認済みのアダプターは、USB ID `0bda:c820`を使用する
`8821cu`対応製品です。同じ製品名でも、製造時期によってUSB IDや内蔵チップが
異なる場合があります。上のドライバー名に近い製品名だけでは、対応を判断できません。
接続できない場合は、PCでUSB IDを確認して報告してください。

## ネットワークサービス

`START -> ネットワーク設定 -> NWサービス`を開きます。チェックをONにすると
サービスが起動し、次回以降の起動時にも有効になります。

下の`V90S_IP`には、`ネットワーク設定 -> インフォメーション`に表示される
IPアドレスを入れます。例: `192.168.1.120`

| サービス | 接続方法 |
| --- | --- |
| SSH | 22番ポートへ`ssh root@V90S_IP` |
| SFTP | SSHと同じアドレス、アカウント、ポート |
| FTP | 21番ポートの`ftp://V90S_IP`。書き込み可能な匿名接続 |
| Samba | `smb://V90S_IP/SDCARD`。ユーザー`plumos`、パスワード`plumos` |
| ADB | ローカルUSB接続から`adb shell`を使う開発用接続 |

SSHのパスワードは変更できます。使用しないサービスはOFFにしてください。
ADBは開発・調査用です。自分が管理するPCへUSB接続した時だけ使用してください。

## USB Disk Mode

USB Disk Modeを使うと、SD1の`PLUMOS`をUSBメモリーのようにPCへ表示できます。
大きなROMやアップデートファイルも直接コピーできます。

1. ゲームとファイル転送を終了します。
2. V90SのUSBポートをPCへ接続します。
3. NWサービスで`USB Disk Mode`を有効にします。
4. PCに表示された`PLUMOS`ドライブへファイルをコピーします。
5. WindowsまたはmacOSでドライブを安全に取り外します。
6. USB Disk ModeをOFFにするかケーブルを抜きます。V90Sで`PLUMOS`が再び使えるまで待ちます。

PCに`PLUMOS`が表示されている間、V90SからROMやアップデートファイルへは
アクセスできません。ADBとUSB Disk Modeは同時に使用できません。
