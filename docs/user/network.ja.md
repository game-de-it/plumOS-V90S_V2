# ネットワークとUSB接続

V90SにはWi-Fiが内蔵されていません。ネットワーク接続には、対応するUSB Wi-Fi
アダプターをOTGポートへ直接、または相性の良い電源付きHUBを介して接続します。

## Wi-Fi

1. USB Wi-Fiアダプターを接続します。
2. `START -> ネットワーク設定`を開きます。
3. Wi-FiをONにします。
4. 「Wi-Fiへ接続」を開いてスキャンし、SSIDを選びます。
5. 画面キーボードでパスワードを入力して確定します。

IPアドレスを取得した時点で設定が保存されます。時刻設定で自動時刻を有効にすると、
Wi-Fi接続後に時刻を同期します。アダプターが切断された場合は接続し直し、Wi-Fiを
OFF、ONしてください。

## ネットワークサービス

`START -> ネットワーク設定 -> NWサービス`を開きます。チェックをONにすると
サービスが起動し、次回以降の起動時にも有効になります。

| サービス | 接続方法 |
| --- | --- |
| SSH | 22番ポートへ`ssh root@V90S_IP` |
| SFTP | SSHと同じアドレス、アカウント、ポート |
| FTP | 21番ポートの`ftp://V90S_IP`。書き込み可能な匿名接続 |
| Samba | `smb://V90S_IP/SDCARD`。ユーザー`plumos`、パスワード`plumos` |
| ADB | ローカルUSB接続から`adb shell`を使う開発用接続 |

SSHパスワードは実機固有の状態で、管理者が変更できます。使用しないサービスは
OFFにしてください。特にADBは、信頼できるローカルUSBホスト向けです。

## USB Disk Mode

USB Disk Modeは、SD1のp4 `PLUMOS` FAT32領域全体を、書き込み可能なUSBストレージ
として公開します。小さな中継領域の容量制限を受けず、大きなROMやアップデート
アーカイブを転送できます。

1. ゲームとファイル転送を終了します。
2. V90SのUSBポートをPCへ接続します。
3. NWサービスで`USB Disk Mode`を有効にします。
4. マウントされた`PLUMOS`ドライブへファイルをコピーします。
5. WindowsまたはmacOSでドライブを安全に取り外します。
6. USB Disk Modeを終了するかケーブルを抜き、plumOSが検査と再マウントを終えるまで待ちます。

PCが領域を使用している間、フロントエンドとネットワークファイルサービスから
ユーザー領域へはアクセスできません。ADBとUSB Disk Modeは同時に使用できません。
