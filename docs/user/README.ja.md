## 主な機能

- テキスト・グラフィカル表示に対応したフロントエンド
- RetroArch、PicoArch、スタンドアロンエミュレータ
- ROM・BIOS用SD2カード
- ギャラリー表示とネットワークスクレイピング
- ファイルマネージャー、音楽プレイヤー、Pyxel、PortMaster
- 対応USB Wi-FiアダプターによるWi-Fi接続
- SSH、FTP、SFTP、Samba、ADB、USB Disk Mode
- 内蔵スピーカーのモノラルミックスとUSB DACのステレオ出力
- 安全な再起動、シャットダウン、スリープ、署名付きアップデート

## 重要事項

ROMおよびゲームBIOSは同梱されません。合法的に入手したデータを用意してください。
SDカードを抜く前には、必ずフロントエンドの「シャットダウン」を実行してください。
アップデート中やストレージ処理中に電源を切らないでください。
