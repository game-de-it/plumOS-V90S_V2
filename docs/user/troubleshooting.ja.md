# トラブルシューティング

## 初回起動が終わらない

初回起動はSDカードを準備するため、通常より時間がかかります。安定した電源へ接続して
待ってください。失敗メッセージが消えない場合は画面を写真に撮り、可能なら画面の案内から
終了します。PCで`PLUMOS/plumos-logs/`も確認してください。直らない場合は、SDカードへ
イメージを書き直します。

## システムやゲームが表示されない

- ROMフォルダ名と拡張子を確認します。
- SD2がFAT32で、直下に`roms/`と`bios/`があることを確認します。
- `START -> UI設定 -> TOPを更新`を実行します。
- 全設定システムを確認したい場合だけ、空のシステムを表示する設定を有効にします。

## 見た目が同じROM名が二つ表示される

日本語ファイル名は、見た目が同じでもPC内部の記録方法が異なることがあります。
macOSとWindowsなど、異なる環境から同じROMをコピーすると、同じ名前が二つある
ように表示される場合があります。ROMが壊れているとは限りません。

1. ROMをPCへバックアップします。
2. 見た目が同じファイルを整理し、必要な一方だけを残します。
3. 整理したROM一式を、できるだけ同じPC・同じ転送方法でコピーし直します。
4. `START -> UI設定 -> TOPを更新`を実行します。

同じPCから同じ名前のファイルをもう一度コピーした場合は、通常は上書きされます。
異なるPCやアプリからコピーした時だけ、見た目が同じ別ファイルになることがあります。
重複を整理してからサムネイル画像を取得してください。

## ゲームが起動しない

- 必要なBIOSが指定どおりのファイル名であることを確認します。
- cue、プレイリスト、トラック、関連フォルダをまとめて保持します。
- ROMリストでSELECTを押し、別の起動方法を試します。
- 保存した設定が原因と思われる場合は、対象エミュレータを初期設定へ戻します。

## Wi-Fiへ接続できない

- V90Sには対応USB Wi-Fiアダプターが必要です。
- アダプターを接続し直し、Wi-FiをOFF、ONします。
- SSIDスキャンが終わるまで次のボタンを押さずに待ちます。
- ネットワーク情報でWi-Fi名（SSID）とIPアドレスを確認します。
- OTGへ直接接続するか、別の電源付きUSB HUBを試します。

## 音が出ない

- 本体の音量プラスボタンでシステム音量を上げます。
- USB DACを接続し直し、経路が切り替わるまで少し待ちます。
- アプリ固有のミュートや音量設定を確認します。
- 機器固有の音声設定を変えた後は、ゲームを終了して起動し直します。

## PCからフォーマットを求められる

キャンセルしてください。PCはSD1内のLinux用領域を読めません。
普段ファイルを入れる場所は`PLUMOS`です。不明な領域をフォーマットしないでください。

## 安全でないリセットや取り外しを行った後

次回起動時のSDカード検査が終わるまで待ちます。時間がかかっても、復旧画面を途中で
止めないでください。今後はSDカードを抜く前に「シャットダウン」を実行します。
