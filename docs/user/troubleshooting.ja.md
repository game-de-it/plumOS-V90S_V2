# トラブルシューティング

## 初回起動が終わらない

初回のストレージ設定は通常起動より時間がかかるため、安定した電源へ接続して待ちます。
失敗メッセージが表示されたままの場合は、可能なら画面の案内から終了し、PCで
`PLUMOS/plumos-logs/`を確認してください。初期設定を完了できない場合は、配布イメージを
書き直す方法が最も確実です。

## システムやゲームが表示されない

- ROMフォルダ名と拡張子を確認します。
- SD2がFAT32で、直下に`roms/`と`bios/`があることを確認します。
- `START -> UI設定 -> TOPを更新`を実行します。
- 全設定システムを確認したい場合だけ、空のシステムを表示する設定を有効にします。

## 見た目が同じROM名が二つ表示される

日本語ファイル名には、画面上では同じでも内部のUnicode表現が異なるものがあります。
macOSなどが使う分解形（NFD）と、Windowsや多くのLinux環境が使う合成形（NFC）が
混在すると、FAT32上で別の名前として共存し、フロントエンドには同じROMが二つある
ように表示される場合があります。これはROMデータの破損を直接意味しません。

1. ROMをPCへバックアップします。
2. 見た目が同じファイルを整理し、必要な一方だけを残します。
3. 整理したROM一式を、できるだけ同じPC・同じ転送方法でコピーし直します。
4. `START -> UI設定 -> TOPを更新`を実行します。

同じUnicode表現の同名ファイルをWindowsとFTPから転送した場合は、通常は既存ファイルが
上書きされ、二重にはなりません。転送元やアプリによってNFCとNFDが混在した場合だけ、
見た目が同じ別名ファイルが作られる可能性があります。スクレイピングもそれぞれを別名と
して扱うことがあるため、重複を整理してからサムネイルを取得してください。

## ゲームが起動しない

- 必要なBIOSが指定どおりのファイル名であることを確認します。
- cue、プレイリスト、トラック、ディレクトリをまとめて保持します。
- ROMリストでSELECTを押し、表示される別のエミュレータプロファイルを試します。
- 保存済み設定が起動を妨げる場合は、対象エミュレータのファクトリー設定を復元します。

## Wi-Fiへ接続できない

- V90Sには対応USB Wi-Fiアダプターが必要です。
- アダプターを接続し直し、Wi-FiをOFF、ONします。
- SSIDスキャンが終わるまで次のボタンを押さずに待ちます。
- ネットワーク情報でインターフェース、SSID、IPアドレスを確認します。
- OTGへ直接接続するか、別の電源付きUSB HUBを試します。

## 音が出ない

- 本体の音量プラスボタンでシステム音量を上げます。
- USB DACを接続し直し、経路が切り替わるまで少し待ちます。
- アプリ固有のミュートや音量設定を確認します。
- 機器固有の音声設定を変えた後は、ゲームを終了して起動し直します。

## PCからフォーマットを求められる

キャンセルしてください。WindowsとmacOSはLinuxのext4システム領域を読めません。
表示されたplumOSのFAT領域だけを使い、不明なパーティションをフォーマットしないでください。

## 安全でないリセットや取り外しを行った後

次回起動時のファイルシステム検査が終わるまで待ちます。低速な復旧画面を途中で
中断しないでください。以後はストレージを外す前にフロントエンドのシャットダウンを
使用します。
