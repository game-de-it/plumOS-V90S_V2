# システムとエミュレータ

plumOSには複数のゲーム起動方法があります。ゲーム機の種類に合わせて、
RetroArch、PicoArch、または専用エミュレータを使います。

## ゲームの起動

1. TOP画面でシステムを選びます。
2. ROMリストまたはギャラリーでゲームを選びます。
3. Aボタンで起動します。

起動前にSELECTを押すと、別の起動方法を選べます。選んだ方法はゲーム機ごとに
保存されます。選択肢が1つだけの場合は、そのまま起動します。

## 起動方法の種類

- **RetroArch（RA）** は最も多くのゲーム機に対応し、ゲーム中に設定メニューを
  開けます。
- **PicoArch（PICO）** は動作が軽い起動方法です。対応するゲーム機だけで選べます。
- **Standalone（SA）** は、そのゲーム機専用のエミュレータを使います。
  メニューやボタン操作はエミュレータごとに異なります。

ゲーム機によって、選べる起動方法は異なります。V90Sで使用できない組み合わせは
表示されません。

## ゲームファイルの置き場所

ゲームは`roms/`内の機種別フォルダへ置きます。CDゲームなどが複数ファイルに
分かれている場合は、cue、プレイリスト、トラック、サブフォルダをまとめて
コピーしてください。一部のファイルだけを改名しないでください。

BIOSは`bios/`内へ置きます。必要なBIOSとファイル名はエミュレータごとに
決まっています。ファイル名や大文字・小文字を変更しないでください。
アーケードゲームは、選んだエミュレータに対応するROMセットが必要です。

## パフォーマンス

通常はCPU速度を自動調整する`ondemand`を使います。重いゲームの動作が遅い場合は、
`START -> パフォーマンス設定`で機種を選び、`performance`を試してください。
「初期値に戻す」で元に戻せます。

重いゲームは、設定を変えても十分な速度が出ないことがあります。
早送りの速さもゲーム機とゲームによって異なります。

## エミュレータ設定

RetroArch、PicoArch、PPSSPPなどの対応エミュレータで保存した変更は、システム
領域に保持されます。初期設定へ戻す場合は、次を使用します。

`START -> システム設定 -> ファクトリーリセット`

すべての設定を戻すか、RA、PicoArch、スタンドアローンのどれかだけを戻すかを
選べます。現在の設定は、初期設定へ戻す前にバックアップされます。
