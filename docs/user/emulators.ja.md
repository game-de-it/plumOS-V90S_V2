# システムとエミュレータ

plumOSは、システムに応じてRetroArch、PicoArch、またはスタンドアローン
エミュレータでゲームを起動します。選択肢はシステムとインストール済み
ランタイムによって異なります。

## ゲームの起動

1. TOP画面でシステムを選びます。
2. ROMリストまたはギャラリーでゲームを選びます。
3. Aボタンで起動します。

起動前にSELECTを押すと、利用可能な別のエミュレータプロファイルを選べます。
選択内容はシステムごとに保存されます。対応プロファイルが1つだけの場合は、
そのまま起動します。

## プロファイル

- **RetroArch（RA）** は最も多くのコアに対応し、ゲーム中のメニューを備えます。
- **PicoArch（PICO）** は、V90S用プロファイルがあるシステムだけで使う軽量な
  libretroフロントエンドです。
- **Standalone（SA）** はRetroArchを介さずにエミュレータを起動します。
  メニューやショートカットは各エミュレータによって異なります。

すべてのコアをすべてのフロントエンドで選べるわけではありません。V90S用の
起動プロファイルがない組み合わせは表示されません。

## コンテンツの配置

ゲームは`roms/`以下の各システムフォルダへ置きます。複数ファイルで構成される
ディスクゲームは、cue、プレイリスト、トラック、サブディレクトリをまとめて
保持してください。cueとトラックの一方だけを改名しないでください。

BIOSは`bios/`以下へ置きます。必要なファイル名とハッシュはエミュレータごとに
決まっているため、元のファイル名と大文字小文字を維持してください。
アーケードROMセットは、選択したコアまたはエミュレータの版と一致させます。

## パフォーマンス

CPUガバナーの初期値は`ondemand`です。高負荷なゲームで継続的なCPU速度が必要な
場合は、`START -> パフォーマンス設定`でシステムを選び、`performance`へ変更します。
「初期値に戻す」で通常のシステムプロファイルへ戻せます。

高性能を必要とするシステムでは、ゲーム別設定、フレームスキップ、軽い
エミュレータプロファイルが必要になることがあります。早送り速度もシステムと
ゲームによって異なります。

## エミュレータ設定

RetroArch、PicoArch、PPSSPPなどの対応エミュレータで保存した変更は、システム
領域に保持されます。初期設定へ戻す場合は、次を使用します。

`START -> システム設定 -> ファクトリーリセット`

すべてのエミュレータ設定、RAのみ、PicoArchのみ、スタンドアローンのみを選べます。
置き換え前の現在の設定はバックアップされます。
