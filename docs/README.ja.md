# plumOS V90S ドキュメント

文書は利用対象ごとに分けています。英語版は`.md`、日本語版は`.ja.md`です。

## ユーザー向け

[ユーザー向け取扱説明書](user/README.ja.md)には、インストール、操作、ストレージ、
ROM・BIOS、ネットワーク、アップデート、セーブ、復旧手順を記載します。
開発実験や検証履歴は含めません。

## 開発者向け

[開発者向けガイド](developer/README.ja.md)には、vendor境界、4パーティションの
ブートフロー、Dockerビルド、app-layer管理、エミュレータ起動経路、
ハードウェアサービス、アップデート、リリース検査、検証記録を収録します。

既存のポリシー、計画、調査、検証ファイルは開発者向け資料として分類し、同ガイドから
索引します。過去のリンクを維持するため、ファイル自体は現在のパスに残します。
