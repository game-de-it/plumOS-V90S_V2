# V90S plumOS Boot Logo Validation

Date: 2026-07-19

## Asset Contract

The supplied `plumos-a30-hero01.png` was imported as the editable source:

```text
package/boot-assets-v90s/bootlogo.png
```

It was converted without scaling to the V90S bootloader format:

```text
package/boot-assets-v90s/bootlogo.bmp
Windows 3.x BMP
640x480
24-bit BI_RGB
921654 bytes
sha256=6b4be39f18289bffe0a9ea65c11f0d479fd12946bd67154ae7332350df795fa8
```

An ImageMagick absolute-error comparison between the PNG flattened on black
and the BMP returned zero differing pixels.

## Build Integration

The four-partition assembler now overwrites the old vendor-runtime
`bootlogo.bmp` after copying the remaining p1 resources. Preflight validates
the BMP header, and final image verification extracts `PLUMBOOT:/bootlogo.bmp`
and compares it byte-for-byte with the repository asset.

The generated seed image passed all partition and payload checks:

```text
output/images/plumos-v90s-four-partition-20260719-1.img
size=2772979712
sha256=32888d4c38a48286888cb27f37c7bf7334b7dc23a583f1d21bc6fbe995266280
verification=PASS
```

## Live Deployment

The same BMP was copied to the running device through ADB. p1 was remounted
read-write only for the staged copy and atomic rename, synchronized, and then
returned to read-only:

```text
/dev/mmcblk0p1 on /mnt/plumos-boot type vfat (ro,...)
/mnt/plumos-boot/bootlogo.bmp
sha256=6b4be39f18289bffe0a9ea65c11f0d479fd12946bd67154ae7332350df795fa8
staged_file=absent
```

The new image will be visible from the next bootloader startup.
