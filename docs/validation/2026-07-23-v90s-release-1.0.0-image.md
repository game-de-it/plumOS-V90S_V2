## Purpose

Generate the four-partition provisioning SD image for plumOS V90S 1.0.0
against the fixed `v90s-stockos-r1` vendor runtime.

The supported `release-image` target was run end to end. It checks and
materializes the tracked non-emulator baseline, checks and prepares the tracked
vendor baseline, rebuilds only RetroArch, all libretro recipes, PicoArch, and
standalone emulators, then assembles the strict app-layer, boot package, boot
image, and verified SD image.

## Host Verification

The strict app-layer build, license audit, and full image preflight passed. The
generated `.sha256` file also passed an independent `shasum -a 256 -c` check.
The image verifier passed:

- 640x480 24-bit V90S boot logo source
- GPT seed geometry: p1 1024 MiB, p2 64 MiB, p3 1600 MiB, p4 absent
- raw boot0 and boot-package regions
- p2 provisioning Android boot image
- p1 PLUMBOOT resources and A/B System SquashFS payloads
- p3 PLUMOS_SYS ext4 runtime and frontend payload
- 347 MiB free in the p3 seed

First boot remains responsible for expanding p3 to 8192 MiB and creating p4
FAT32 `PLUMOS` through the remaining card capacity.

## Remaining Release Gate

This record proves the generated artifact and its host-visible contents. It
does not prove that this exact image has booted on a V90S. Before final release,
write the image to an SD card and complete the physical cold-boot, controls,
display, audio, representative runtime, persistence, shutdown, and reboot
