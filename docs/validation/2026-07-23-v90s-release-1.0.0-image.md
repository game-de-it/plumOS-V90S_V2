## Purpose

Generate the four-partition provisioning SD image for plumOS V90S 1.0.0
against the fixed `v90s-stockos-r1` vendor runtime.

The current source was used to rebuild the vendor preparation, PPSSPP
standalone launcher and factory defaults, frontend, System SquashFS, strict
app-layer, boot package, and boot image. Other emulator and application
payloads came from the previously validated local component build baseline and
were reassembled under the strict app-layer manifest and checksum gate.

## Host Verification

The strict app-layer build, license audit, and full image preflight passed. The
generated `.sha256` file also passed an independent `shasum -a 256 -c` check.
The image verifier passed:

- 640x480 24-bit V90S boot logo source
- GPT seed geometry: p1 1024 MiB, p2 64 MiB, p3 1600 MiB, p4 absent
- raw boot0 and boot-package regions
- p2 provisioning Android boot image
- p1 PLUMBOOT resources and A/B System SquashFS payloads
- p3 PLUMOS_SYS ext4 runtime and frontend payload
- 346 MiB free in the p3 seed

First boot remains responsible for expanding p3 to 8192 MiB and creating p4
FAT32 `PLUMOS` through the remaining card capacity.
