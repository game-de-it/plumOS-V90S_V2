# V90S PPSSPP Factory Identity Sanitization

Date: 2026-07-23

## Goal

Prevent a device-generated PPSSPP identity from becoming a shared factory
default in public releases.

## Finding

The tracked `ppsspp.ini` was originally captured from the validated live V90S
configuration. Its `MacAddress` value was generated by PPSSPP and was not the
physical MAC address of the V90S or its USB Wi-Fi adapter. Shipping that value
as a factory default would nevertheless give every new installation the same
emulated PSP network identity.

PPSSPP v1.20.4 treats a missing or non-17-character value as invalid and
generates a random MAC address during post-load cleanup. The factory setting is
therefore now intentionally empty:

```ini
MacAddress =
```

The sanitized tracked configuration hash is:

```text
446a4f6557fb3aea26ce86b2554887a88f99b141716b8a97074974c895003a3e  ppsspp.ini
```

## Release Gates

The standalone-emulator build rejects a source factory configuration unless it
contains exactly one empty `MacAddress` entry. The final release packager checks
the assembled app layer independently, so stale standalone output with the old
fixed value cannot be released.

## Host Validation

- shell syntax checks pass for both modified build scripts
- the tracked factory configuration passes the empty-value check
- a temporary configuration with a fixed MAC address is rejected by the same
  check
- no physical network identity, credential, save, or ROM content is involved

The next full release build should regenerate standalone and app-layer outputs
before packaging. Existing device-owned PPSSPP settings remain unchanged by a
normal update; the sanitized factory value applies to first initialization and
explicit factory reset.
