plumOS V90S vendor runtime notice

plumOS V90S uses a POWKIDDY V90S StockOS/Batocera-derived low-level runtime
identified by plumOS as v90s-stockos-r1. This runtime provides the boot chain,
Linux 4.9.191 kernel and modules, PowerVR GE8300 firmware and userspace
libraries, display support, audio support, and hardware-specific input support.

They retain the terms, notices, and restrictions of their original licensors
and upstream projects. The plumOS repository records their source device,
file inventory, and hashes in the prepared vendor-runtime manifest and
SHA256SUMS. plumOS-authored extraction, packaging, configuration, and adapter
code remains covered by the repository LICENSE.

The public repository carries a sanitized copy of this fixed vendor input so a
clean clone can reproduce the SD-image build. Active StockOS password material,
boot random seed, Wi-Fi values, ROMs, game BIOS files, saves, and personal keys
are excluded from that copy.

No ROM or BIOS game content is covered by this notice or distributed as part
of plumOS releases.
