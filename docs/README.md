# plumOS V90S Documentation

This documentation is divided by audience. English files use `.md`; Japanese
counterparts use `.ja.md`.

## For Users

The [User Guide](user/README.md) is an operating manual. It covers installation,
controls, storage, ROMs, BIOS files, networking, updates, saves, and recovery.
It intentionally omits development experiments and validation history.

## For Developers

The [Developer Guide](developer/README.md) covers the complete technical model:
the vendor boundary, four-partition boot flow, Docker builds, app-layer
ownership, emulator launch paths, hardware services, updates, release checks,
and validation evidence.

Existing policy, plan, research, and validation files are classified as
developer references and indexed from that guide. They remain at their current
paths to preserve historical links.
